# 云极智能拆版 V1.2

对标「若海AI PLT自动拆版」，专为 POD 数码印花服装工厂打造：**更智能 · 更合理 · 更标准**。

**V1.1 新增**：多码数套排拆版、自动选码打样、左右袖/前后片自动标注、小尺码标（可选项）、每裁片二维码（对标若海）、版师点位/缝制线/矢量描边标准化。

**V1.2 新增**：
- **蒙版写死进 PSD**：每个「图案_xxx」占位层自带裁片形状图层蒙版（PSD 原生蒙版通道），放入印花图案即被自动裁切成裁片形状，无需任何手动操作——蒙版成为拆版体系的固有产物
- **拆版总览按码分组**：多码文件总览图「一码一区」——第 S 码 / 第 M 码 / 第 L 码各占一个板块，组内按 前片→后片→左袖→右袖→领条 顺序整齐排列，一目了然

## 一、三大升级（对比若海）

| 维度 | 若海AI自动拆版 | 云极智能拆版 |

| **更智能** | 按 PLT 转 PSD、图层命名 | ① PLT 矢量 + 位图(PNG) 双通道拆版 ② 裁片特征AI分析：自动区分 **前片/后片/袖片/领条罗纹/袋片** ③ 领口缺口深度判定前后片 ④ **多码数自动拆版**：识别 S/M/L/XL 码标 → 按码套分组命名（前片1/后片1/左袖1/右袖1/领条罗纹1 × 每码） ⑤ **自动选码打样**：指定码数只拆该码一套 ⑥ 异常件自动警示 |
| **更合理** | 沿边重组、固定间距 | ① 天空线高精度排料（shapely 精确碰撞）② **经向约束**：主裁片长边沿布长方向 ③ 旋转/间距/门幅全可调 ④ 省料率实时计算 ⑤ 多码分码分行排料 |
| **更标准** | 小耳朵码标、定位点 | ① PSD 分组分层：裁片组/码标组/小尺码标组/二维码组/**缝制线组/版师点位组** ② **每裁片独立二维码**（若海同款：裁片可追溯）③ **矢量路径资源**（每裁片轮廓写入 PSD 路径，Photoshop 可编辑矢量描边）④ 缝制线标准蓝色虚线、版师点位标准十字 ⑤ **图案层写死裁片形状蒙版**（开箱即用，放图自动裁切）⑥ 命名模板化 + JSX 一键转智能对象 ⑦ 用量报表 |

## 二、功能清单

**输入**
- [x] PLT/HPGL 矢量文件（服装 CAD 导出，自动单位归一、闭合环修复、碎环滤除）
- [x] PNG / BMP / JPG 位图（OpenCV 二值化 + 形态学闭运算 + 连通域拆版）

**拆版与识别**
- [x] 闭合环 → 裁片（含孔洞归属，如领口、扣位）
- [x] 非闭合线（定位点/锁眼/缝线）自动归入所属裁片
- [x] 轮廓简化（RDP）+ 多边形平滑
- [x] 智能分类：前片 / 后片 / 袖片 / 领片 / 领条罗纹 / 袋片 / 贴片 / 挂耳 / 其他
- [x] 前后片区分：领口缺口深度启发式
- [x] **多码拆版**：PLT 文本码标（S/M/L/XL…）识别 + 码套分组（分行排料自动聚类）
- [x] **左右袖 / 前后片自动标注**（可选项，默认开）：同码内袖片按主件位置分左/右并独立编号
- [x] **自动选码拆版**（打样）：`--size M` 只拆 M 码一套，自动重命名
- [x] 异常检测：碎屑件、低凸度怪形件、顶点爆炸件 → 红色警示

**码标 / 尺码标 / 二维码（均可选项）**
- [x] 大耳标（码标）：白底红字，宽度/高度/文字模板可配（默认 12×6mm，默认开）
- [x] **小尺码标**：默认关；开时每个裁片生成小码标（inside/outside 可调，9×4.5mm）
- [x] **整体二维码**：内容模板可配，默认 `款号|码数|日期|YJSPLIT`
- [x] **每裁片二维码**（对标若海）：默认关；开时每个裁片角落生成独立二维码，内容模板 `{article}-{size}-{name}`

**排料（更合理）**
- [x] 天空线 + shapely 精确多边形碰撞（非包围盒）
- [x] 经向固定：主裁片长边沿布长方向
- [x] 旋转：90/180/270 步进可开关；角度按经向正确优先
- [x] 间距可调（默认 6mm）、门幅可调
- [x] 输出排料长/宽/利用率/用料米数

**版师标准标注（均可选项，默认开）**
- [x] **缝制线**：PLT 内 LT1 虚线样式 → PSD 独立「缝制线」组，标准蓝色虚线（0.2mm）
- [x] **版师点位**：PLT 内短十字线 → PSD 独立「版师点位」组，标准红色十字（0.2mm）
- [x] **矢量描边**：每个裁片轮廓写入 PSD 路径资源（ID 0x0BB8 起），Photoshop 路径面板可编辑

**导出（更标准）**
- [x] PSD 分层文件：裁片组（裁片层+图案占位层+定位点层）、码标组、小尺码标组、二维码组、缝制线组、版师点位组
- [x] 批量转智能对象 JSX 脚本（Photoshop 一键执行）
- [x] 拆版总览 PNG、排料图 PNG
- [x] 拆版报表 JSON（面积/尺寸/码数/每裁片二维码内容/警告/用量）

## 三、快速开始

### 方式 A：直接运行（有 Python）
```bash
pip install -r requirements.txt
python app.py                  # 图形界面
python app.py --cli 版型.plt    # 命令行
```

### 方式 B：Windows 一键打包成 EXE
1. 安装 Python 3.9+（https://python.org，勾选 Add to PATH）
2. 双击 `build.bat`
3. 完成后 `dist\云极智能拆版V1.2.exe` 即为绿色免安装程序

### 图形界面操作步骤
1. ① 导入：选择 `.plt` 或 `.png` 版型文件
2. 左侧设置参数（码标规格、门幅、间距、命名模板等，均有默认值）
3. ② 一键智能拆版：自动完成 解析→拆版→智能命名→码标→排料
4. 查看「拆版总览」和「省料排料图」两个页签，异常件红框提示
5. ③ 导出：选文件夹 → 输出 PSD / PNG / 报表 / JSX

### 命令行示例
```bash
# 单码普通拆版
python app.py --cli samples/sample_t-shirt.plt --article T-1001 ^
  --sheet-w 1600 --gap 6 --dpi 150 --canvas-w 1100 --canvas-h 800

# 多码拆版 + 小尺码标 + 每裁片二维码 + 版师标准标注（全部开启）
python app.py --cli samples/sample_t-shirt_3码.plt --article T-2001 ^
  --sheet-w 1350 --canvas-w 1350 --canvas-h 1000 --size-label --qr-per-piece

# 自动选码打样：只拆 M 码一套
python app.py --cli samples/sample_t-shirt_3码.plt --article T-2001 ^
  --sheet-w 1350 --size M
```

**可选项开关**（默认：耳标开 / 小尺码标关 / 每裁片二维码关 / 左右袖开 / 缝制线开 / 点位开 / 矢量路径开）：

| 命令行 | 作用 |
|---|---|
| `--no-ear` | 关闭大耳标 |
| `--size-label` | 开启小尺码标 |
| `--qr-per-piece` | 开启每裁片二维码 |
| `--no-lr` | 关闭左右袖自动标注 |
| `--no-sew` | 关闭缝制线导出 |
| `--no-marker` | 关闭版师点位导出 |
| `--no-vector` | 关闭矢量路径写入 |
| `--no-qr` | 关闭整体二维码 |
| `--size M` | 只拆 M 码（打样） |

## 五、输出物

| 文件 | 说明 |
|---|---|
| `云极智能拆版_{款号}_分层.psd` | 分层 PSD（裁片组/码标/尺码标/二维码/缝制线/版师点位/矢量路径/**图案层自带裁片形状蒙版**） |
| `{款号}_拆版总览.png` | 各裁片彩色标注总览（**按码分组：一码一区**，含码数/尺码标） |
| `{款号}_排料图.png` | 排料布局 + 利用率 |
| `拆版报表.json` | 面积/尺寸/码数/每裁片二维码/警告/用料数据 |
| `批量转智能对象.jsx` | Photoshop 脚本：把「图案_*」占位层批量转为智能对象 |

**智能对象用法**：用 Photoshop 打开 PSD → 文件 > 脚本 > 浏览 → 运行 `批量转智能对象.jsx`，
「图案_前片1」等占位层即变为智能对象，双击即可替换印花图案，图案自动按裁片形状裁切。
V1.2 起**图案层已写死裁片形状蒙版**——即使不运行 JSX，直接把图案拖入图案层，也会被蒙版
自动裁切成裁片形状（蒙版是 PSD 原生通道，整套体系内建，非外部脚本补充）。

**版师标准标注**：PSD 内「缝制线」组为标准蓝色虚线（0.2mm，源 PLT 的 LT1 虚线样式）、
「版师点位」组为标准红色十字（0.2mm，源 PLT 短十字线）；每个裁片轮廓同时写入 PSD
路径资源（路径面板可选中编辑，矢量描边不随像素缩放失真）。

## 六、技术架构

```
app.py  ── PySide6 UI（暗黑科技风）
  └─ core/pipeline.py         一键拆版主管线
      ├─ plt_parser.py        PLT/HPGL 解析（单位归一/闭合修复）
      ├─ vector_split.py      矢量拆版（闭合环→多边形→孔洞归属→简化）
      ├─ piece_analysis.py    AI 识别：特征工程+评分分类+前后片+异常检测
      ├─ ear_label.py         小耳朵码标
      ├─ qr_gen.py            二维码
      ├─ nesting.py           天空线排料（经向约束/旋转/碰撞）
      ├─ psd_export.py        PSD 分层导出 + JSX
      ├─ preview.py           预览渲染
      └─ report.py            用量报表
```

## 七、已知限制与后续

- [ ] PLT 中部分加密/自定义扩展指令（如个别 CAD 的 PE 编码坐标）暂按标准 HPGL 处理，遇到解析异常会提示
- [ ] 前后片区分依赖领口缺口形态，无领口的款式（如直筒裤）将按对称件命名，可在导出后手动改名
- [ ] 多码分组依赖排料分行结构（同码同排）或 PLT 内码标文本；混排且无码标的文件按几何聚类兜底，极端布局下可手动调整
- [ ] 下一步可扩展：面料缩率补偿、DXF 导出、裁片面积按缩率修正、多码混合套排优化
